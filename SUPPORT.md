# Support

## Get help or report a defect

Open a [GitHub Issue](https://github.com/TedTschopp/github-repository-health/issues/new) for:

- questions about applying or interpreting the repository-health standard;
- reproducible defects in the assessment engine, reports, workbook, examples,
  or documentation;
- proposals for a control, measure, methodology profile, or reporting change;
  and
- requests to clarify trial-use or pilot guidance.

Include the standard version, repository type and risk tier, the relevant
control or measure ID, the smallest reproducible example, expected behavior,
actual behavior, and any non-sensitive output. Do not attach tokens, private
repository content, personal information, raw secret findings, or confidential
security evidence.

This project is maintained on a best-effort basis. The maintainer targets an
initial response within ten business days, but no support service level is
offered. Version `0.1.0-draft` is provisional and improvement-diagnostic; a
health grade is not a certification or release approval.

## Security issues

Do not use a public Issue for a suspected vulnerability. Follow
[SECURITY.md](SECURITY.md) and submit it through GitHub private vulnerability
reporting.

## Normative changes

Changes to a requirement, threshold, gate, scoring rule, or methodology profile
must follow [CONTRIBUTING.md](CONTRIBUTING.md). A support answer does not amend
the standard; accepted normative changes require the documented review and
version record.
